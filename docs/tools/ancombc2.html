ANCOM-BC2

Differential abundance analysis for multiple groups, with covariate adjustment and repeated measures.

Microbiome differential abundance released R Python QIIME 2

ANCOM-BC2 extends ANCOM-BC to multigroup comparisons. It supports fixed and random effects, and therefore covariate adjustment and repeated measures. It provides a global test, pairwise comparisons, comparisons against a reference group (Dunnett-type), and trend tests across ordered groups, with control of the mixed directional false discovery rate.

Extended tutorial

The R tutorial applies ANCOM-BC2 to the HITChip Atlas data set of intestinal microbiota profiles from Western adults, distributed with the microbiome package as atlas1006. The analysis compares the abundance of each taxon, aggregated at the Family rank of the data set, across three body mass index (BMI) groups (lean, overweight, obese), adjusted for age and geographic region.

Model and hypotheses

Let \(o_{ij}\) denote the observed abundance of taxon \(i\) in sample \(j\), and let \(\mathbf{x}_j\) denote the covariate vector of sample \(j\), including an intercept. ANCOM-BC2 assumes

\[ \log o_{ij} = d_j + \mathbf{x}_j^\top \boldsymbol{\beta}_i + \varepsilon_{ij}, \]

where \(d_j\) is the log sampling fraction of sample \(j\) and \(\varepsilon_{ij}\) is a mean-zero error. For repeated measures, random effects are added to the linear predictor through rand_formula.

Let \(\beta_{i,\mathrm{ow}}\) and \(\beta_{i,\mathrm{ob}}\) denote the coefficients of taxon \(i\) for the overweight and obese groups, with lean as the reference. The analysis tests four families of hypotheses.

Test Null hypothesis Alternative
Primary \(\beta_{ik} = 0\) for one coefficient \(k\) \(\beta_{ik} \neq 0\)
Global \(\beta_{i,\mathrm{ow}} = \beta_{i,\mathrm{ob}} = 0\) at least one is nonzero
Pairwise directional equal abundance in a pair of groups, for every pair a difference with its direction
Dunnett type equal abundance in a group and the reference, for every non-reference group a difference with its direction
Trend \(\beta_{i,\mathrm{ow}} = \beta_{i,\mathrm{ob}} = 0\) a monotone pattern across the ordered groups

The pairwise and Dunnett-type tests control the mixed directional false discovery rate, which accounts for both the multiple comparisons within a taxon and the multiplicity across taxa.

Analysis

The trend test requires the monotone patterns as inequality constraints \(A\boldsymbol{\theta} \ge 0\) on \(\boldsymbol{\theta} = (\beta_{i,\mathrm{ow}}, \beta_{i,\mathrm{ob}})^\top\). The pattern \(0 \le \beta_{i,\mathrm{ow}} \le \beta_{i,\mathrm{ob}}\) (increasing) and the pattern \(0 \ge \beta_{i,\mathrm{ow}} \ge \beta_{i,\mathrm{ob}}\) (decreasing) are specified as two contrast matrices.

increasing <- matrix(c( 1, 0,
                       -1, 1), nrow = 2, byrow = TRUE)
decreasing <- matrix(c(-1,  0,
                        1, -1), nrow = 2, byrow = TRUE)
set.seed(123)
out <- ancombc2(data = tse, assay_name = "counts", tax_level = "Family",
                fix_formula = "age + region + bmi", rand_formula = NULL,
                p_adj_method = "holm", pseudo_sens = TRUE,
                prv_cut = 0.10, lib_cut = 1000, s0_perc = 0.05,
                group = "bmi", struc_zero = TRUE, neg_lb = TRUE,
                alpha = 0.05, n_cl = 2, verbose = FALSE,
                global = TRUE, pairwise = TRUE, dunnet = TRUE, trend = TRUE,
                iter_control = list(tol = 1e-2, max_iter = 20, verbose = FALSE),
                em_control = list(tol = 1e-5, max_iter = 100),
                lme_control = lme4::lmerControl(),
                mdfdr_control = list(fwer_ctrl_method = "holm", B = 100),
                trend_control = list(contrast = list(increasing, decreasing),
                                     node = list(2, 2),
                                     solver = "ECOS", B = 100))
Argument Role
fix_formula, rand_formula Fixed and random effects of the log-linear model.
group Grouping variable for structural zero detection and for the global, pairwise, Dunnett-type, and trend tests.
pseudo_sens Sensitivity analysis of each result to the addition of pseudo-counts to zeros.
s0_perc Percentile of the standard errors added to the denominator of the test statistic, which limits significance caused by very small standard errors.
global, pairwise, dunnet, trend Multigroup tests to perform.
mdfdr_control Procedure and number of bootstrap samples B for the mixed directional false discovery rate.
trend_control Contrast matrices, position of the nodal parameter, and number of bootstrap samples B for the trend test.

Primary results

The element res is a data frame with one row per taxon. For each model coefficient it contains the following columns.

Column prefix Content
lfc_ Log fold change (natural log)
se_ Standard error
W_ Test statistic, lfc / se
p_, q_ p-value and adjusted p-value
diff_ TRUE if the adjusted p-value is below alpha
passed_ss_ TRUE if the result does not change with the pseudo-count added to zeros
diff_robust_ TRUE if both diff_ and passed_ss_ are TRUE 
res <- out$res

Pairwise directional test

The element res_pair contains the three pairwise comparisons. Columns with the suffix bmioverweight and bmiobese compare each group with lean. Columns with the suffix bmiobese_bmioverweight compare obese with overweight.

ANCOM-BC2 is available in scikit-bio from version 0.7.4.

pip install scikit-bio
from skbio.stats.composition import ancombc2

The arguments and the structure of the result are listed in the function reference.

The command in this tab is shown for reference and is not executed on this page.

ANCOM-BC2 is an action of the q2-composition plugin, which is included in the QIIME 2 amplicon distribution.

qiime composition ancombc2 --help

The inputs, parameters, and outputs are listed in the plugin reference.

A web tool for this method is in development. This tab will hold its link and a walk-through at release.
