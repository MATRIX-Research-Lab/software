SECOM

Sparse estimation of linear and nonlinear correlations between taxa in microbiome data.

Microbiome correlation released R

SECOM (sparse estimation of correlations among microbiomes) estimates correlations between pairs of taxa, within one ecosystem or across ecosystems. secom_linear estimates sparse Pearson or Spearman correlations after bias correction. secom_dist estimates distance correlation, which also detects nonlinear relationships.

Extended tutorial

The R tutorial applies SECOM to the HITChip Atlas data set of intestinal microbiota profiles from Western adults, distributed with the microbiome package as atlas1006. The analysis estimates the correlation between each pair of taxa, aggregated at the Family rank of the data set.

Model

Let \(o_{ij}\) denote the observed abundance and \(a_{ij}\) the unobserved absolute abundance of taxon \(i\) in sample \(j\). SECOM assumes

\[ \log o_{ij} = \log c_i + \log s_j + \log a_{ij}, \]

where \(c_i\) is the taxon-specific sequencing efficiency and \(s_j\) is the sample-specific sampling fraction. The term \(\log s_j\) is shared by all taxa in sample \(j\) and therefore induces correlation between observed abundances that is absent from the absolute abundances. SECOM estimates this sample-specific bias, subtracts it, and computes correlations from the bias-corrected log abundances.

Two estimators are available.

Function Measure Detects
secom_linear Pearson or Spearman correlation Linear or monotone relationships
secom_dist Distance correlation Linear and nonlinear relationships

Linear correlation

set.seed(123)
res_linear <- secom_linear(data = list(tse), assay_name = "counts",
                           tax_level = "Family", pseudo = 0,
                           prv_cut = 0.5, lib_cut = 1000, corr_cut = 0.5,
                           wins_quant = c(0.05, 0.95), method = "pearson",
                           soft = FALSE, thresh_len = 20, n_cv = 10,
                           thresh_hard = 0.3, max_p = 0.005, n_cl = 2)
Argument Role
data A list of data objects, one per ecosystem. One element gives correlations within one ecosystem.
prv_cut Taxa present in a smaller proportion of samples are excluded.
corr_cut A taxon whose correlation with the estimated sample-specific bias exceeds this value is flagged, and its pairwise correlations are set to 0.
wins_quant Quantiles at which extreme abundances are winsorized.
soft, thresh_len, n_cv Thresholding operator, number of candidate thresholds, and number of cross-validation folds for the thresholded estimate.
thresh_hard Correlations with absolute value at or below this value are set to 0.
max_p Correlations with a p-value above this value are set to 0 in the filtered estimate.

The result contains three estimates of the correlation matrix.

Element Content
corr Sample correlation matrix of the bias-corrected abundances
corr_th Sparse matrix obtained by thresholding, with the threshold chosen by cross-validation
corr_fl Sparse matrix obtained by p-value filtering at max_p

A function for drawing a correlation matrix is defined once and used for each estimate.

plot_corr <- function(mat, limits = c(-1, 1), label = "Correlation") {
  as.data.frame(as.table(mat)) |>
    setNames(c("taxon1", "taxon2", "value")) |>
    mutate(taxon2 = fct_rev(taxon2)) |>
    ggplot(aes(x = taxon1, y = taxon2, fill = value)) +
    geom_tile(color = "white") +
    geom_text(aes(label = ifelse(value == 0, "", sprintf("%.2f", value))),
              size = 2.6) +
    scale_fill_gradient2(low = "#3f9ae0", mid = "white", high = "#f2775f",
                         midpoint = 0, limits = limits, name = label) +
    labs(x = NULL, y = NULL) +
    coord_fixed() +
    theme_minimal(base_size = 11) +
    theme(axis.text.x = element_text(angle = 45, hjust = 1),
          panel.grid = element_blank())
}
plot_corr(res_linear$corr_fl)
plot_corr(res_linear$corr_th)

Distance correlation

Distance correlation takes values in \([0, 1]\) and equals 0 only under independence. The p-values are obtained from R permutation replicates.

set.seed(123)
res_dist <- secom_dist(data = list(tse), assay_name = "counts",
                       tax_level = "Family", pseudo = 0,
                       prv_cut = 0.5, lib_cut = 1000, corr_cut = 0.5,
                       wins_quant = c(0.05, 0.95), R = 1000,
                       thresh_hard = 0.3, max_p = 0.005, n_cl = 2)
plot_corr(res_dist$dcorr_fl, limits = c(0, 1), label = "Distance\ncorrelation")

Comparison of the two estimators

A pair of taxa with a nonzero filtered distance correlation and a zero filtered Pearson correlation is a candidate for a nonlinear relationship.

upper <- upper.tri(res_linear$corr_fl)
taxa  <- rownames(res_linear$corr_fl)

pairs <- tibble(
  taxon1   = taxa[row(res_linear$corr_fl)[upper]],
  taxon2   = taxa[col(res_linear$corr_fl)[upper]],
  pearson  = res_linear$corr_fl[upper],
  distance = res_dist$dcorr_fl[upper]
)

c(pairs               = nrow(pairs),
  pearson_nonzero     = sum(pairs$pearson != 0),
  distance_nonzero    = sum(pairs$distance != 0),
  distance_only       = sum(pairs$distance != 0 & pairs$pearson == 0))

Correlation between two ecosystems

To estimate correlations between taxa from two ecosystems measured on the same subjects, pass both data objects in data, for example data = list(gut = tse_gut, oral = tse_oral), with matching sample names. The result is one correlation matrix over the taxa of both ecosystems.
