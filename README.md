# MATRIX Software

Source of the MATRIX Research Lab software website, published at <https://matrix-research-lab.github.io/software/>.

The site is a [Quarto](https://quarto.org) website. Rendered output is written to `docs/`, which GitHub Pages serves from the `main` branch.

## Build

The script `render.sh` works from any directory. It uses `quarto` from `PATH` when available, and otherwise the conda environment `quarto` (`conda create -n quarto -c conda-forge quarto`).

```bash
./render.sh            # writes docs/
./render.sh preview    # live preview at http://localhost:8002
```

Pages with executed R code (for example `tools/ancombc.qmd`) are run once and their results are stored in `_freeze/`; they are executed again only when their source changes. R and the packages used in the tutorials are required only for that execution. Stop the live preview before running `./render.sh`.

Keep the folder outside cloud-synchronized locations such as Google Drive: Quarto creates and removes cache files faster than such services can synchronize them.

## Structure

- `index.qmd`: front page. Its content is generated by `assets/front.ejs` from the front matter of the method pages; `assets/front.js` handles the interaction.
- `tools/`: one `.qmd` file per method.
- `tutorials/`: tutorial index; each extended tutorial is one `.qmd` file in this folder.
- `community.qmd`: discussion forum and issue trackers.
- `assets/`: theme (`theme.scss`), styles (`site.css`), front page template and script.

## Adding a method

Create `tools/<id>.qmd` with this front matter. The front page and the Tools table update at the next render.

```yaml
title: "Method name"
description: "One sentence stating the purpose."
area: "Microbiome differential abundance"   # the category shown on the front page
order: 4                                     # position within the category
status: released                             # or: in development
platforms:
  - name: R                                  # R, Python, QIIME 2, GNPS, Web tool
    url: https://...
  - name: Python
    status: planned                          # shown with a dashed outline
related: [ancombc2]                          # ids (file names) of related methods
```

A new `area` value creates a new category; add its icon to the `areas` list in `assets/front.ejs`.
